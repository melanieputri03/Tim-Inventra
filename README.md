# Tim-Inventra

## Deskripsi
Smart Inventory merupakan platform Software as a Service (SaaS) berbasis mobile yang dirancang untuk membantu UMKM fashion dalam mengelola inventori secara lebih efektif dan efisien. Sistem ini dilengkapi fitur Artificial Rule-Based Recommendation berbasis Knowledge-Based Expert System yang mampu memberikan rekomendasi restock berdasarkan histori penjualan, kondisi stok, dan aturan bisnis yang telah ditetapkan. Selain mendukung pengelolaan stok dan transaksi, Smart Inventory juga menyediakan dashboard analitik, notifikasi stok minimum, serta laporan penjualan untuk membantu pengambilan keputusan yang lebih cepat dan berbasis data.
